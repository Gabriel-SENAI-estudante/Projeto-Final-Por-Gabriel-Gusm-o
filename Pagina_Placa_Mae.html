Placa-mãe

A placa-mãe (ou motherboard) é o componente principal de um computador, responsável por conectar todos os componentes de hardware. Ela fornece a estrutura física e lógica para que os componentes se comuniquem entre si, garantindo o funcionamento adequado do sistema. As placas-mãe modernas são projetadas para suportar diferentes tipos de processadores, memórias e cartões de expansão, oferecendo flexibilidade e desempenho otimizado.
